# M1/T4 — эталонный прогон проп-MC на синтетике

**Это не рынок.** Сделки сгенерированы `pbl prop synth` с известными свойствами: 750 дней Пн–Пт
(2023-01-02 … 2025-11-14), сделка в 80% дней, винрейт 45%, стоп −1R, тейк +1.5R, издержки
0.06R на сделку (спред 60%, проскальзывание 40%), вход 14:30–15:30 UTC. Ожидание ≈ +0.065R
на сделку — тонкий перевес, на котором видно, как правила и стрессы режут вероятность.

Спек инструментов ещё нет (T6), поэтому лот не округляется (κ = 1) и все размеры одной
программы дают одинаковую P — отличаются только взносом и EV.

Воспроизвести (seed фиксирован, результат совпадает):

```bash
uv run pbl prop synth --out data/synthetic/trades.csv
uv run pbl prop run data/synthetic/trades.csv --out reports/m1-t4-synthetic
```

Файлы: `summary.md` — отчёт, `prop_table.csv` — все строки таблицы программ,
`manifest.json` — seed, коммит, хэши сделок и профилей, N, L.
