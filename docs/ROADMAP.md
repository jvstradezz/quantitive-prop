# ROADMAP — вехи M0–M7

Статус: черновик M0 · 2026-10-28

Правила: одна задача = тред = ветка = PR; не больше 3 тредов одновременно; модель и effort — по таблице роутинга из инструкций проекта. После каждой вехи — короткий отчёт: что готово, как проверить, что дальше.

## Обзор

| Веха | Суть | Зависит от |
|---|---|---|
| M0 | Документы и каркас | — |
| M1 | Проп-Monte Carlo на списке сделок ‖ данные Dukascopy + выгрузка платформы + спецификации | M0 |
| M2 | Движок бэктеста с издержками и внутридневной эквити + окно идей через чат (первой — идея №1) | M1 |
| M3 | Робастность и автоотказ | M2 |
| M4 | Автопоиск по всем рынкам (генерация, массовый скан, ночной запуск) + портфели | M3 |
| M5 | Дашборд на реальных данных + страница «Идеи» с GitHub-триггером | M2 (данные), M4 (leaderboard) |
| M6 | Демо-форвард-раннер | M3, VPS |
| M7 | Адаптер исполнения + предохранители + Telegram | M6 |
