# DESIGN — дашборд

Статус: черновик M0 · 2026-10-28

Тёплый «редакционный» стиль в духе приложения Claude, но свой: без логотипов, названий и ассетов Anthropic. Перед UI-задачей — смотреть референсы в `/mnt/project-files` и этот документ; использовать skill `frontend-design`, если доступен.

## 1. Требования Nikita (дословно)

- Светлая тема: фон #F4F2EC, поверхность #FBFAF7, текст #1F1E1C, вторичный #6E6B63, линии #E3E0D6, акцент терракота #C8643F, плюс #2E7D5B, минус #B5473A.
- Тёмная тема: фон #1E1D1B, поверхность #282725, текст #EEEBE3, вторичный #A29F96, линии #393834, акцент #D9774F.
- Заголовки — serif (Newsreader), интерфейс — Inter, цифры — JetBrains Mono с tabular-nums.
- Сетка 8pt, карточки с рамкой 1px и радиусом 12px, почти без теней, тонкие линии графиков. Без неона, градиентов и стекла. Переключатель тем, адаптив под телефон.
- Страница стратегии: equity, просадка, веер MC, walk-forward, тепловая карта параметров, разбивка издержек, сделки. Prop simulator: таблица типов пропов, P по фазам, причины провалов, риск по фазам. Bots: статус, P&L дня против лимитов фирмы, kill switch.

## 4. Сетка и элементы

- Шаг 8pt: 8, 16, 24, 32, 48, 64 (4 — только внутри плотных элементов).
- Карточки: `--surface`, рамка 1px `--line`, радиус 12px, тень — нет или едва заметная.
- Кнопки и поля: радиус 8px `[предложено]`, рамка 1px.
- Брейкпоинты: 640 / 768 / 1024 / 1280 `[предложено]`. На телефоне широкие таблицы скроллятся внутри своего контейнера, страница горизонтально не скроллится.
- Переключатель темы: по умолчанию системная, ручной выбор запоминается.

## 5. Графики

- Lightweight Charts, линии 1.5px, сетка `--line`.
- Эквити — `--text`, просадка — заливка `--neg` с прозрачностью (ровный цвет, без градиента).
- Веер MC: полоса 5–95% — `--accent` 12%, 25–75% — `--accent` 24%, медиана — линия `--accent`.
- Плюс / минус — только `--pos` / `--neg`. Без неона, градиентов, стекла.
- Тепловая карта параметров — последовательная шкала от `--surface` к `--accent`; точка текущих параметров обведена.

## 6. Экраны

| Экран | Содержимое |
|---|---|
| Идеи | поле ввода как чат (текст, голос, скрины, ссылки, видео); карточки идей со статусами (Новая → … → Демо / Отклонена); фильтр по статусу; карточка: суть, сессии в ET и МСК, допущения, результаты, вердикт, кнопка «доработать» |
| Leaderboard | таблица стратегий: место по P(1-я выплата), лучшая программа, EV на взнос, PF OOS, DSR, сделок, стадия S0–S6, флаг издержек > 30%; фильтры по рынку, семейству, статусу |
| Стратегия | equity, просадка, веер MC, walk-forward, тепловая карта параметров, разбивка издержек, сделки |
| Prop simulator | таблица типов пропов, P по фазам, причины провалов, риск по фазам; кривая P от риска; переключатели стрессов |
| Bots | статус, P&L дня против лимитов фирмы (и внутренних предохранителей), kill switch |

Время на всех экранах — ET и МСК; время сервера брокера — явно, где речь о торговом дне.
