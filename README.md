# quantitive-prop

Конвейер поиска стратегий и ботов для CFD-пропов: бэктест с издержками, отбраковка переобученных стратегий, Monte Carlo прохождения пропа с подбором риска по фазам, окно идей и автопоиск.

Метрика успеха — вероятность дойти до первой выплаты на живых данных.
